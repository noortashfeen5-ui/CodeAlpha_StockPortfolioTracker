# CodeAlpha_StockPortfolioTracker 📈

A real-time **Stock Portfolio Tracker** built in Python to help users monitor investment performance, stock prices, and portfolio value.

## 🚀 Quick Start
Run `Stock_portfolio_Tracker.ipynb` directly in **Google Colab** or **Jupyter Notebook** to track your portfolio.

## ✨ Key Features
- 📊 **Real-Time Data**: Tracks active stock prices and performance.
- 💰 **Portfolio Valuation**: Calculates total investment returns automatically.
- ⚡ **Easy Integration**: Lightweight and simple to execute.
